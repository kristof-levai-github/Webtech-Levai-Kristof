GitHub felhasználó keresése

- A GitHub felhasználókeresés token megadása nélkül működik (nincs saját token a kliens oldali kódban).

- Mivel a kód githubra kerül, a token beágyazása nyilvánossá válna, ezért nem lenne teljesen biztonságos.

FONTOS: Mivel nincs megadva token, ezért csak 60 keresést lehet végezni percenként és csak a publikus felhasználók kereshetők
